# SpringTwelve 电源面板回归清单

构建/静态检查不能替代真机验收。所有重启和关机操作只允许用户在测试机保存数据、结束通话后手动确认；构建脚本不执行这些操作。

## 不破坏成功基线

- 自动录音、录音列表、路径解析与 MUtoolRecord/MUtoolMixer 相对 f583596 保持不变。
- 开启自动录音后，接通电话自动录制；挂断后列表能看到并播放成品。

## 入口和中文确认

- 桌面空白处长按打开电源菜单；图标、部件、文件夹上的普通触摸不应误触。
- 每个实际可用的动作都显示中文标题、风险提示、“确认执行”和“取消”。
- 取消只返回主菜单，不发送信号/系统操作；随后可再次选择任意动作。
- 快速重复点选、重复确认、旧事件回调不应重复执行或撤销更新的请求。
- 确认期间锁屏、离开桌面、失去前台、窗口被其他 UI 接管后，旧确认不得执行。
- VoiceOver 返回手势先取消确认，再关闭主菜单；大字体下风险提示可滚动，按钮可达。

## 实际操作（逐项分开测试）

- 快速注销：发送 SIGTERM 给当前 SpringBoard。记录是否重新进入桌面。
- 强制注销：发送 SIGKILL 给当前 SpringBoard。记录是否重新进入桌面。
- 请求安全模式：发送 SIGSEGV 给当前 SpringBoard，是否进入安全模式取决于越狱崩溃处理器，不保证。
- 重启桌面：系统服务动作，不能把发送请求等同于完成重启。
- 重启用户空间：应重启服务而非硬件；记录越狱是否保持及系统恢复情况。
- 重启设备：整机重启，确认提示须说明可能需要重新激活越狱。
- 关机：整机关闭，需要手动开机，确认提示须明确。
- 运行时 API 不可用或请求失败时，给出中文原因，禁止自动改执行更强的动作。
